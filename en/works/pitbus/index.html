PitBus

An event bus for agents

View on GitHub
Language
Python
License

Platform
macOS
Updated
Nov 10

Keeps an eye on Slack, Lark doc comments, Google Calendar, GitHub and points in time, sorting everything into three states: waiting on you, waiting on others, and done. When a Claude Code session is waiting for a reply, PitBus wakes it up the moment something happens — no polling, no tokens spent.
