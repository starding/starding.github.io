LessonML

A scripting language for interactive lessons, written for language models

View on GitHub
Language
TypeScript
License
Apache-2.0
Status
Early draft
Updated
Nov 10

Gives a lesson the shape of a story: characters, scenes you keep coming back to, and a learner who acts inside them — spotting claims that can’t be verified, choosing how to respond. The model writes the script; the compiler checks it against a world catalog and returns diagnostics written for the model. Characters are parameterized, so the whole art style can be swapped.
